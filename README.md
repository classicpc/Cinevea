# Cinevea

A voice- and text-driven movie ticket booking app. Users pick a location, browse a live movie catalog, choose a date/showtime, select seats on a live seat map, and confirm a booking — guided by a conversational assistant (OpenAI-powered, with a rule-based fallback) and optional voice input.

## Tech stack

- **Frontend:** React 18 + TypeScript, Vite, Tailwind CSS, lucide-react icons
- **Backend:** Supabase (Postgres + Auth + Row Level Security + Edge Functions)
- **Edge Functions (Deno):**
  - `sync-omdb` — populates the movie catalog from the [OMDb API](https://www.omdbapi.com/) and generates synthetic theatres/showtimes per city (OMDb has no cinema/showtime data of its own)
  - `chat` — conversational booking assistant backed by OpenAI (`gpt-4o-mini`), grounded in live catalog data from Supabase
  - `transcribe` — voice-to-text via OpenAI Whisper

## Project structure

```
src/
  App.tsx              Main booking flow (movie → date → showtime → tickets → seats → review → confirm)
  types.ts             Shared types, demo constants, ticket type pricing
  hooks/useAuth.ts      Supabase auth session handling
  components/           Auth screen, header, voice input, chat transcript
  lib/
    conversation.ts     Assistant engine: OpenAI chat function + rule-based fallback
    supabase.ts         Supabase client init
    speech.ts           Browser text-to-speech playback

supabase/
  functions/
    sync-omdb/          Populates movies/theatres/showtimes from OMDb
    chat/               OpenAI-backed conversational assistant
    transcribe/         OpenAI Whisper voice transcription
  migrations/           Schema: locations, movies, theatres, auditoriums, showtimes,
                         showtime_seats, seat_holds, bookings, ticket_types,
                         plus RPCs for seat holds/booking confirmation and a
                         pg_cron job that releases expired seat holds every minute
```

## Database schema (high level)

- `locations` → `theatres` → `auditoriums` → `showtimes` → `showtime_seats`
- `movies` (synced from OMDb)
- `ticket_types` — Adult / Senior / Child / Student pricing multipliers
- `seat_holds` — temporary 5-minute seat reservations (`reserve_showtime_seats` RPC), auto-released by a scheduled `pg_cron` job
- `bookings` — confirmed bookings (`confirm_held_booking` RPC), cancellable via `cancel_booking`

All tables have Row Level Security enabled; booking/seat-hold mutations go through `SECURITY DEFINER` RPC functions rather than direct table writes.

## Getting started

### Prerequisites

- Node.js 18+
- A [Supabase](https://supabase.com) project
- An [OMDb API key](https://www.omdbapi.com/apikey.aspx) (free tier)
- An [OpenAI API key](https://platform.openai.com/api-keys) with available credits

### 1. Install dependencies

```bash
npm install
```

### 2. Configure the frontend

Create `.env.local` in the project root:

```
NEXT_PUBLIC_SUPABASE_URL=https://<your-project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=<your-anon-or-publishable-key>
```

### 3. Configure and deploy Supabase

```bash
npx supabase login
npx supabase link --project-ref <your-project-ref>

# Apply all migrations
npx supabase db push

# Set edge function secrets
npx supabase secrets set OMDB_API_KEY=<your-omdb-key>
npx supabase secrets set OPENAI_API_KEY=<your-openai-key>

# Deploy edge functions
npx supabase functions deploy sync-omdb
npx supabase functions deploy chat
npx supabase functions deploy transcribe
```

### 4. Populate the movie catalog

`sync-omdb` has no cinema data of its own, so each call creates one synthetic theatre for a given city and schedules showtimes for a curated list of movie titles:

```bash
curl -X POST https://<your-project-ref>.supabase.co/functions/v1/sync-omdb \
  -H "Authorization: Bearer <anon-key>" \
  -H "Content-Type: application/json" \
  -d '{"titles": ["Oppenheimer", "Dune: Part Two"], "city": "Toronto", "theatreName": "Cinevea Downtown", "days": 7}'
```

Omit `titles` to use the built-in default list. Call it once per city you want to support.

### 5. Run the app

```bash
npm run dev
```

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check with no emit
- `npm run lint` — ESLint

## Notes

- If `OPENAI_API_KEY` has no billing credits, the `chat` function returns an error and the frontend falls back to a rule-based conversational engine driven by the live Supabase catalog — the app still works, just without free-form natural language understanding.
- Showtimes generated by `sync-omdb` are written in Toronto local time (fixed `-05:00` offset; does not account for daylight saving).
